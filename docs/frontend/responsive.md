# Responsive layout

Design mobile-first. Use fluid widths constrained by the 36 rem form and 72 rem shell widths. Use 16 px horizontal padding on narrow screens and increase to 24 or 32 px where space permits. Keep form labels above inputs and use a single reading column until a second column has room without crowding controls.

At narrow widths stack form actions, requirement rows, and supplemental cards. Keep statuses beside their labels where they fit. Preserve visible primary actions in document flow. Use wrapping for long addresses, filenames, and validation messages. Keep meaningful tabular relationships with a labeled scroll container where reflow would lose that association.

Verify representative 320, 375, 768, and 1280 CSS px widths, landscape viewport, text zoom, keyboard order, and touch targets. Select breakpoints based on content behavior. Verify dialogs remain scrollable with the focused control visible.
